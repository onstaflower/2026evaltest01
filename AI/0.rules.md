# 0. 개발 및 SDD 운영 규칙 (Rules)

본 문서는 **학생 손글씨 서술형 평가 AI 채점 웹앱** 개발을 위한 코드 컨벤션, 보안 가이드, Streamlit 아키텍처 및 SDD 운영 원칙을 정의합니다.

---

## 1. SDD (Spec-Driven Development) 운영 원칙
1. **문서 동기화 최우선**: 모든 작업 시작 전 `AI/` 폴더 내 문서 상태를 확인하고, 작업 완료 시 즉시 업데이트합니다.
2. **체크박스 기반 진척도 추적**: `AI/2.design.md`, `AI/3.tasks.md`, `AI/4.plan.md`, `AI/5.execution.md`의 모든 항목은 `- [ ]` / `- [x]`로 상태를 추적합니다.
3. **무손실 컨텍스트 기록**: `AI/9.notes.md`에 [일시], [작업 내용], [결정 사항], [수정 파일 목록]을 팩트 위주로 누적합니다.
4. **역질문 원칙**: 모호한 요구사항이나 추가 기능 논의 시 5개의 체계적인 역질문을 제시하여 명세를 확정합니다.

---

## 2. 코드 컨벤션 & Python/Streamlit 규칙
1. **Python 3.10+ 표준 준수**:
   - PEP 8 스타일 가이드 준수 (snake_case 함수/변수, PascalCase 클래스).
   - 모든 핵심 함수에 Type Hinting 및 명확한 Docstring 작성.
2. **Streamlit UI/UX 및 상태 관리 (`st.session_state`) 최적화**:
   - 렌더링 루프 방지를 위해 세션 상태(`st.session_state`)를 체계적으로 초기화하고 단일 진실 공급원(Single Source of Truth)으로 활용.
   - 대용량 API 호출 및 시트 조회는 `@st.cache_data` / `@st.cache_resource` 데코레이터를 활용하여 중복 호출 방지 및 속도 최적화.
   - UI는 탭(`st.tabs`) 또는 사이드바 네비게이션으로 [1. 학생 제출 모드]와 [2. 교사 채점/관리 모드]를 깔끔하게 분리.
3. **모듈 분리 원칙**:
   - `app.py`: UI 레이아웃, 세션 관리, 사용자 인터랙션 핸들링.
   - `sheets_handler.py`: Google Sheets API 연동 (명단 조회, 채점 데이터 저장/업데이트, 인증).
   - `gemini_evaluator.py`: Gemini 1.5 Flash 멀티모달 OCR 및 루브릭 기반 평가 프롬프트 엔지니어링.
   - `utils.py`: PDF/텍스트 루브릭 파싱, 이미지 전처리 및 공통 유틸리티.

---

## 3. 보안 및 API 키 관리 가이드
1. **절대 하드코딩 금지**:
   - Google Gemini API Key 및 Google Service Account JSON 등 모든 인증 정보는 코드 내에 직접 작성하지 않음.
2. **Streamlit Secrets & 환경변수 활용**:
   - 로컬/배포 환경에서는 `.streamlit/secrets.toml` 또는 `.env` 파일을 활용.
   - 저장소 커밋 방지를 위해 `.gitignore`에 `.streamlit/secrets.toml`, `*.json`(서비스 계정 키), `__pycache__/` 등록 필수.
   - 배포용 템플릿(`.streamlit/secrets.toml.template`)을 제공하여 사용자가 쉽게 설정할 수 있도록 지원.

---

## 4. 100% 무료 티어 운영 원칙
- **UI & 호스팅**: Streamlit Community Cloud (무료)
- **AI 멀티모달 모델**: Google Gemini 1.5 Flash (Free Tier - 분당 RPM/RPD 한도 내 최적 토큰 운용)
- **데이터베이스/스토리지**: Google Sheets API (Google Cloud Free Tier & Google Drive)
