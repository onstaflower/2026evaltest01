## 2. 실행 방법 가이드 (Local Run)

```bash
# 1. 의존성 패키지 설치
pip install -r requirements.txt

# 2. Streamlit 웹앱 실행
streamlit run app.py
```

브라우저에서 `http://localhost:8501`로 접속하여 즉시 테스트할 수 있습니다.
