# 1. 사용자 요구사항 정의서 (Requests)

## 1. 프로젝트 개요
- **프로젝트명**: 손글씨 서술형 평가 AI 채점 & 결과 관리 웹앱
- **타겟 사용자**: 
  - **학생**: 로그인 없이 간편하게 학년/반/번호/이름 선택 후 손글씨 답안지 다중 업로드 및 제출
  - **교사**: 채점 기준(루브릭) 등록, AI 자동 채점 실행, 결과 확인 및 수동 수정, 재채점, 구글 시트 데이터 영속 관리
- **운영 환경**: 윈도우 데스크톱 브라우저 및 모바일 웹 대응, 100% 무료 스택(Streamlit, Gemini 1.5 Flash Free Tier, Google Sheets API)

---

## 2. 확정된 핵심 요구사항 명세

### [RQ-01] 명단 관리 (Student Roster via Google Sheets)
- 구글 스프레드시트에 기입된 [학년 / 반 / 번호 / 이름] 명단 데이터를 실시간 로드.
- 학생 제출 화면 및 교사 관리 화면에서 드롭다운(Selectbox)으로 학생을 손쉽게 선택 가능하도록 구성.
- 구글 시트 연결 실패 시 로컬 데모/폴백 모드로 동작 가능하도록 안내 및 기본 템플릿 지원.

### [RQ-02] 루브릭 설정 (Evaluation Rubric Management)
- 교사가 서술형 평가의 채점 기준 문서(PDF, TXT, 또는 직접 텍스트 입력)를 업로드/등록.
- 평가 항목별 배점, 성취 기준, 채점 가이드라인, 모범 답안 등을 AI에게 시스템 프롬프트로 전달.
- 설정된 루브릭은 세션에 캐싱되어 모든 학생의 채점에 일관되게 적용.

### [RQ-03] 학생 답안 제출 (Student Multi-Image Submission)
- 별도의 회원가입/로그인 절차 없이 (학년/반/번호/이름) 선택.
- 서술형 답안지 손글씨 사진을 **"여러 장 연속 업로드(Multi-file upload)"** 가능 (PNG, JPG, JPEG, WEBP).
- 업로드된 이미지들의 미리보기(Thumbnail Preview) 및 순서 확인 기능 제공.
- 제출 버튼 클릭 시 즉시 채점 대기열 또는 자동 채점 파이프라인으로 전송.

### [RQ-04] AI 멀티모달 OCR 및 자동 채점 (Gemini 1.5 Flash Multimodal)
- Google Gemini 1.5 Flash 모델에 답안지 다중 이미지와 루브릭 기준을 함께 전송.
- **손글씨 인식(OCR)**: 이미지 속 손글씨 텍스트를 정확하게 추출 및 구조화.
- **루브릭 기반 자동 채점**: 문항별 득점, 총점, 감점 사유, 세부 성취 수준 평가.
- **성장형 피드백 생성**: 학생의 강점과 보완점을 구체적인 문장으로 작성(생기부 연계 가능 스타일).

### [RQ-05] 교사용 채점 관리 & 재채점 (Teacher Dashboard & Regrade)
- 데스크톱 브라우저에 최적화된 교사용 관리 대시보드 제공.
- 학생별 원본 답안 이미지, OCR 추출 텍스트, AI 채점 점수, 피드백을 한눈에 비교 검토.
- 교사가 점수나 피드백을 직접 수정/보완할 수 있는 편집 UI 제공.
- 프롬프트나 루브릭을 조정한 후 즉시 **"재채점(Re-grade)"**을 실행할 수 있는 버튼 제공.

### [RQ-06] 구글 시트 데이터 저장 및 동기화 (Google Sheets Sync)
- 학생 제출 내역, 원본 이미지 링크/식별자, OCR 텍스트, 문항별 점수, 총점, 최종 피드백, 채점 일시를 구글 시트에 행 단위로 자동 기록/업데이트.
- 이미 채점된 학생의 경우 덮어쓰기(업데이트) 또는 신규 추가 처리.
- 엑셀/CSV 다운로드 기능 병행 제공.

### [RQ-07] 100% 무료 티어 최적화 및 안정성 (Zero-Cost Architecture)
- Streamlit Community Cloud + Google Gemini 1.5 Flash Free API + Google Sheets API v4 구성.
- API Key 및 서비스 계정 키 안전 관리(Secrets/환경변수).
- 네트워크 지연 및 API Rate Limit(분당 요청 수 제한) 대비 예외 처리 및 재시도 로직 탑재.
